# W1: the workspace builds on Windows

The whole workspace, tests included, compiles on Windows with the MSVC toolchain, and the portable crates' tests pass. Commands that need Windows support from later steps (the daemon, services, trust, the hosts file) fail with a "not supported on Windows yet" error instead of misbehaving. macOS and Linux behave as before.

## Try it

Run from the repository root in Git Bash:

```sh
cargo build --workspace --all-targets --all-features
cargo run -p devlanes -- --version
(cd fixtures/two-services && cargo run -p devlanes -- config check)
git diff --exit-code crates/config/schema.json crates/config/user-schema.json
```

`config check` reads `devlanes.yaml` from the current directory and prints `ok fixture-two` with the file's path. The build regenerates `schema.json` and `user-schema.json`, so the last command passing means Windows produces the same schemas as macOS and Linux.
