# W12: agent plugin

The plugin's `PreToolUse` hook is `devlanes __agent-hook` instead of a `sh` script, so it runs wherever `devlanes` is on `PATH`: Claude Code on macOS, Linux and Windows (Git Bash or PowerShell) and Codex. It matches Claude Code's Bash and PowerShell tools and, besides `&`, `nohup`, `setsid -f`, `tmux new -d` and `screen -dm`, blocks `Start-Process`, `Start-Job`, PowerShell 7's trailing `&` and cmd's `start` when they start a dev server inside a devlanes project. The skill has Windows notes, and a Windows CLI inside Codex's sandbox no longer starts a daemon there.

## Try it

From Git Bash, with a scratch project:

```sh
cargo build -p devlanes
export PATH="$PWD/target/debug:$PATH"
mkdir -p /tmp/acme && echo 'project: acme' > /tmp/acme/devlanes.yaml
dir=$(cygpath -m /tmp/acme)
echo "{\"cwd\":\"$dir\",\"tool_name\":\"PowerShell\",\"tool_input\":{\"command\":\"Start-Process pnpm dev\"}}" | devlanes __agent-hook; echo "exit $?"
echo "{\"cwd\":\"$dir\",\"tool_name\":\"Bash\",\"tool_input\":{\"command\":\"pnpm dev &\"}}" | devlanes __agent-hook; echo "exit $?"
echo "{\"cwd\":\"$dir\",\"tool_name\":\"Bash\",\"tool_input\":{\"command\":\"pnpm dev\"}}" | devlanes __agent-hook; echo "exit $?"
```

The first two print the block message and `exit 2`, the last `exit 0`. In a real session, `claude --plugin-dir ./agent-plugin` from a devlanes project, then ask Claude to run `pnpm dev &` and, with the PowerShell tool, `Start-Process pnpm dev`; both calls come back blocked with the message.
