# W13: Windows packaging

Releases build `x86_64-pc-windows-msvc` and `aarch64-pc-windows-msvc` with a static C runtime and ship `devlanes-VERSION-TARGET.zip` with `devlanes.exe`, `devlanesw.exe`, `devlanes-hosts-service.exe` and `LICENSE`. The executables are signed with Azure Artifact Signing once the account exists. `install.ps1` installs a release into `%LOCALAPPDATA%\Programs\devlanes`, and npm (`@devlanes/win32-x64`, `@devlanes/win32-arm64`) and cargo binstall get the same files from the archives. A running `devlanes.exe` is renamed to `devlanes.exe.old-TIMESTAMP` by `install.ps1`, and `doctor` deletes it once the daemon restarted. npm and binstall can't replace a running executable, so on Windows the update notice and `doctor` say to run `devlanes daemon stop` first. See the Windows section of `packaging/README.md`.

## Try it

From PowerShell in the repository, with release binaries built (`cargo build --release -p devlanes -p devlanes-logon-launcher -p devlanes-hosts-service`):

```powershell
./packaging/scripts/check.ps1 -BinDir target/release
```

It packs the zip twice and compares the hashes, installs it from a local release into a temporary directory without touching `PATH`, reinstalls while a daemon runs from the installed `devlanes.exe` (with its own `DEVLANES_HOME` and ports), and checks that the daemon kept running, that `devlanes.exe.old-*` appeared, and that `doctor` deleted it after `daemon stop`. It ends with `Windows packaging: dry run passed`. `powershell.exe -File packaging/scripts/check.ps1` does the same in Windows PowerShell 5.1.

To try the installer by hand against a local release:

```powershell
$dist = "$env:TEMP\devlanes-release"
./packaging/scripts/package.ps1 -Version 0.1.0 -Target x86_64-pc-windows-msvc -OutDir "$dist\download\v0.1.0"
$hash = (Get-FileHash "$dist\download\v0.1.0\devlanes-0.1.0-x86_64-pc-windows-msvc.zip").Hash.ToLower()
New-Item -ItemType Directory -Force "$dist\latest\download" | Out-Null
"$hash  devlanes-0.1.0-x86_64-pc-windows-msvc.zip" | Set-Content "$dist\download\v0.1.0\SHA256SUMS", "$dist\latest\download\SHA256SUMS"
$env:DEVLANES_INSTALL_BASE_URL = ([Uri]$dist).AbsoluteUri
$env:DEVLANES_INSTALL_DIR = "$env:TEMP\devlanes-installed"
$env:DEVLANES_NO_MODIFY_PATH = '1'
Get-Content -Raw install.ps1 | Invoke-Expression
& "$env:TEMP\devlanes-installed\devlanes.exe" --version
```

It prints `Installed devlanes 0.1.0 to ...` and a note that the directory is not on `PATH`, then `devlanes 0.1.0`. Remove the three environment variables and both directories afterwards.
