# W3: services on Windows

Services and tasks run on Windows. Each unit starts inside its own job object, its output arrives over pipes, and `run:` strings run in Git for Windows' `sh` (or `cmd.exe` with a warning when Git is missing). Names that Windows cannot use as file names are stored under an encoded name, and `devlanes with`, `exec`, `logs` and `daemon logs` work as on macOS and Linux.

## Try it

From the repository root in Git Bash, with an isolated home:

```sh
cargo build -p devlanes -p devlanes-testing
export PATH="$PWD/target/debug:$PATH"
export DEVLANES_HOME="$(cygpath -w "$(mktemp -d)")"
cd fixtures/two-services
devlanes start
devlanes status
devlanes logs api --tail 5
devlanes stop
devlanes daemon stop
```

`start` reports both services ready with their URLs, `status` lists the lane with both running, and `logs` shows the fixture server's lines. After `stop`, no `fixture-server.exe` is left running.
