# W4: terminals, attach and the TUI

`pty: true` units (the default for services) run in a pseudo console (ConPTY), so tools that check for a terminal see one. `devlanes attach` connects your console to a unit, and the TUI runs in Windows Terminal, conhost and WezTerm, opening lane shells in a new Windows Terminal tab. Prompts read from the console, `env export --shell pwsh` prints a script PowerShell can run, and copyable hints use PowerShell quoting.

## Try it

In Windows Terminal, with an isolated home:

```powershell
cargo build -p devlanes -p devlanes-testing
$env:Path = "$PWD\target\debug;$env:Path"
$env:DEVLANES_HOME = "$env:TEMP\devlanes-try"
cd fixtures\two-services
devlanes start
devlanes attach api
```

`attach` shows the unit's screen; Ctrl-C goes to the unit, and Ctrl-A then `d` detaches. Run `devlanes` with no arguments for the TUI, then:

```powershell
devlanes env export --shell pwsh | Out-String | Invoke-Expression
$env:PORT
devlanes stop; devlanes daemon stop
```

The exported variables land in the PowerShell session, including values with quotes or non-ASCII characters.
